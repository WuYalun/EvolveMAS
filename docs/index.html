Test-time self-evolution for multi-agent systems

Agents that learn from each other, within an episode and across episodes.

EvolveMAS pairs every agent with a MemoryAgent. It keeps structured memory while the agents interact, then turns each outcome into knowledge about partners and strategies for the next episode. Model weights stay frozen; your system adds three calls.

The loop

Execute, evaluate, evolve

Every agent runs the same three steps in every episode. Below, each step shows the call your system makes and what it actually produced in the recorded episode above.

Use it

Three calls around the loop you already have

Your system keeps its agents, its message routing and its scoring. EvolveMAS only sees what you hand it, so hidden information stays hidden.

context(agent)Memory and knowledge to add to the agent's prompt before it acts.
observe(agent, events)What the agent saw. Its MemoryAgent updates Episodic, Semantic and Working memory.
end_episode(agent, result)Your task's own result. Interaction Strategies and Partner Profiles are revised from it.

Backends: Claude, any OpenAI-compatible endpoint, or any function llm(system, user) -> str. Turn online or evolve off to ablate either phase.

from evolvemas import EvolveMAS, AnthropicLLM

plugin = EvolveMAS("runs/memory", AnthropicLLM())
for a in agents:
    plugin.register(a.name, profile=a.profile)

for problem in problems:
    for a in agents: plugin.begin_episode(a.name)
    for rnd in range(2):
        replies = {a.name: a.solve(problem, plugin.context(a.name))
                   for a in agents}
        for a in agents:
            plugin.observe(a.name, list(replies.items()))
    result = check(replies, problem.answer)
    for a in agents: plugin.end_episode(a.name, result)

EvolveMAS: A Unified Self-Evolution Framework for Decentralized Multi-Agent Systems

Yalun Wu1, Qiwei Ma2, Bingbing Xu3, Dan Zhang1, Long Bai3, Boyang Wang4, Jiatong Li1, Zheqi Lv5, Shaozu Yuan6, Peiying Wang6, An Zhang7, Jiawei Wang1†, Tat-Seng Chua1†

arXivCode

Decentralized multi-agent systems let LLM agents interact without central control, across cooperative, mixed-motive and adversarial settings. EvolveMAS supports test-time adaptation within and across episodes with one protocol: a dedicated MemoryAgent keeps each agent's Structured Memory outside its reasoning context, and each episode's outcome is distilled into reusable partner profiles and interaction strategies. Across five benchmarks and six configurations it reaches the highest normalized average score among the compared methods, 77.2.

The plug-in on this site is a compact, host-agnostic implementation of the protocol. It is not the paper's experiment code.
