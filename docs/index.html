EvolveMAS

Memory that evolves, for the agents you already have.

A plug-in for multi-agent systems. Each agent gets its own MemoryAgent that keeps structured memory during an episode, and knowledge about partners and strategies that carries into the next one. Model weights stay frozen; integration is three calls.

Add it to your system

Three calls around your existing loop

Your system keeps its agents, its message routing and its scoring. EvolveMAS only sees what you hand it, so hidden-information games stay hidden.

context(agent)The memory and knowledge block to add to the agent's prompt before it acts.
observe(agent, events)What the agent saw this turn. Its MemoryAgent updates Episodic, Semantic and Working memory.
end_episode(agent, result)Your task's own score. Interaction Strategies and Partner Profiles are revised from it.

Backends: Claude through the Anthropic SDK, any OpenAI-compatible endpoint, or any function llm(system, user) -> str. Turn online or evolve off to ablate either phase.

from evolvemas import EvolveMAS, AnthropicLLM

plugin = EvolveMAS("runs/memory", AnthropicLLM())
for a in agents:
    plugin.register(a.name, profile=a.profile)

for problem in problems:
    for a in agents: plugin.begin_episode(a.name)
    for rnd in range(2):
        replies = {a.name: a.solve(problem, plugin.context(a.name))
                   for a in agents}
        for a in agents:
            plugin.observe(a.name, list(replies.items()))
    result = check(replies, problem.answer)
    for a in agents: plugin.end_episode(a.name, result)

How it works

Execute, evaluate, evolve

Within an episode

After each turn the MemoryAgent turns new evidence into Episodic, Semantic and Working memory, kept outside the agent's own context so long sessions do not bloat its prompt.

Across episodes

When an episode is scored, the outcome revises reusable Interaction Strategies and Partner Profiles. Working memory resets; knowledge carries over.

Research

Based on the EvolveMAS paper

The paper evaluates the same protocol on five benchmarks covering cooperative, mixed-motive and adversarial interaction. EvolveMAS reaches the highest normalized average score among the compared methods, 77.2, which is 9.7 points above the strongest setting-specific baseline. The plug-in is a compact, host-agnostic implementation of that protocol; it is not the experiment code.

Yalun Wu, Qiwei Ma, Bingbing Xu, Dan Zhang, Long Bai, Boyang Wang, Jiatong Li, Zheqi Lv, Shaozu Yuan, Peiying Wang, An Zhang, Jiawei Wang, Tat-Seng Chua. arXiv link coming soon.
